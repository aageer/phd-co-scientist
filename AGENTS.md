# Agent instructions

This repository is a **PhD Co-Scientist**. Read skills before acting.

## Skill order

1. `running-co-scientist` for any new research request
2. `surveying-sota` for "what's SOTA / GDM / Stanford"
3. `running-grok-swarm` for parallel coverage or races
4. Stage skills: ethics → generate → critique → rank → evolve → plan → execute → paper → clip → plagiarize-check
5. `discovering-agent-architectures` for Agent_H-class work

## Commands

`/co-scientist` `/sota-survey` `/ideate` `/experiment` `/write-paper` `/swarm` `/discover-architecture` `/phd-weekly`

## Non-negotiables

- No paper without `execution.log`
- No clinical advice
- No exploits or dual-use
- Cite primary papers
- Prefer `python -m swarm`
